# Distributor pitch deck

Place the latest PowerPoint here so distributors can download it from the portal.

## Default filename

```
static/distributor/Inertia_Distributor_Pitch_Deck.pptx
```

Also accepted: `Inertia_Distributor_Pitch_Deck.ppt`, `latest_pitch_deck.pptx`, `latest_pitch_deck.ppt`.

## Override path

Set env var:

```bash
DISTRIBUTOR_PITCH_DECK_PATH=/absolute/path/to/deck.pptx
```

## Portal link

`/distributor/pitch-deck` — visible on My clients, client summary, payouts, and the nav.

Until a file is present, the link shows: “Pitch deck is not available yet…”
