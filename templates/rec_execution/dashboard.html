How to refresh client checks

  • Refresh client checks (primary) — Recent-activity clients (last 7 days): all agents, healer, alerts/tasks, and UI packs.
  • Refresh client checks (outline) — Same unified refresh for all accessible clients.

Both buttons use the same backend. Prefer the primary button for routine runs; use the outline button when you need every accessible client refreshed.

How Recommendation Execution Monitor works

  • Monitors monthly investment workflows and creates issues in category RECOMMENDATION_EXECUTION.
  • Checks: workflow_stalled (with related SLA context in description/details), amount_mismatch.
  • Context understanding: reads workflow notes + schedule notes + monthly schedule notes; uses keyword + regex intent detection.
  • Learning: user feedback should create client patterns for expected delays/behaviors to reduce noise over time.
  • Alerts: orchestrator consolidates issues per client into one alert (instead of this agent creating alerts directly).
