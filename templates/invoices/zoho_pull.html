Fetch Zoho invoices for a date range. Matching uses stored zoho_contact_id when set, otherwise email / name. Per-client pull lives on each client’s Billing card.

Mapping
  • Durable: client.zoho_contact_id = Zoho contact/customer ID.
  • Auto: set on successful match or via client Billing card.
  • Fallback: email exact, then fuzzy name (≥ 0.72).

Shows linked maps, name mismatches, Inertia clients without Zoho, and Zoho contacts without Inertia.
