IMPORTANT: File Name Format

Expected format:

Quote-Equity-SYMBOL-EQ-DD-MM-YYYY-to-DD-MM-YYYY.csv

Example:

Quote-Equity-DIXON-EQ-01-01-2025-to-19-10-2025.csv
  • System will verify stock symbol matches the upload target
  • System will verify date range includes the requested year
  • Date range can be longer than one year (must include requested dates)

File Format Required:

  • CSV or Excel file
  • Required columns:
    • Date (or any column with "date" in the name)
    • close (or any column with "close" in the name)
  • Date format: YYYY-MM-DD, DD-MM-YYYY, or DD-Mon-YY
  • Close price should be numeric (commas in numbers are handled)
  • Column names are case-insensitive

Example CSV format:

Date,series,OPEN,HIGH,LOW,PREV. CLOSE,ltp,close,vwap,52W H,52W L,VOLUME,VALUE,No of trades
