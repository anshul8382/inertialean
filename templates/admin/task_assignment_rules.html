How It Works
  • Workflow Stage: Assigns workflow SLA alerts (e.g. RECOS delay, FUNDS delay) to the configured user.
  • Review Status: Assigns ReviewWorkflow records by status (initiated, sent, meeting, closed) to the configured user.
  • Issue Category: Assigns DataIntegrityIssue records (e.g. PORTFOLIO_PERFORMANCE, RECOMMENDATION_MATCH) to the configured user.
  • RECOMMENDATION_EXECUTION: Uses workflow stage when the issue has a workflow_id in details; otherwise uses the category rule.
  • Priority: Higher priority rules are evaluated first. Use for overrides.
  • Run Backfill: Assigns existing open issues that have no assignee based on current rules. If you see "0 issues assigned", all open issues already have assignees (from a previous run or auto-assignment at creation).
  • Where to see assignments: Go to Recommendation Execution or Data Integrity, then drill into issues by client or workflow. The Assigned To column shows who owns each issue. This does not create entries in Task Management (/tasks).
