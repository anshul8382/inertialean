About Roles

Role Hierarchy:

Roles can inherit permissions from parent roles. This allows you to create specialized roles (e.g., "Senior Advisor") that extend base roles (e.g., "Advisor").

Permissions:

After creating a role, you'll be able to assign specific route permissions. Permissions can be granted or denied per route endpoint.

System Roles:

System roles are protected from deletion. Use this for core roles that are essential to your application.
