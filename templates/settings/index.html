Google Calendar & Tasks

When you are assigned an ops task with a deadline, we can sync it to your primary Google Calendar (deadline event) and to your default Google Tasks list. If you create or host a meeting and your account is used as the calendar host, invites go to team participants and the client/lead email.

In Google Cloud Console, enable Google Calendar API and Google Tasks API for the OAuth client. Set GOOGLE_CALENDAR_CLIENT_ID / SECRET and the redirect URI, run DB migrations, then click Connect Google Calendar here. If you connected before Tasks was enabled, disconnect and connect again to grant Tasks access.
