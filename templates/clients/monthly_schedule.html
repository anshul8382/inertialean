Monthly Investment Schedule

This schedule configures how monthly investments are automatically created for this client.

Priority Order:
  1. Active Schedule: If a schedule exists and is active, it will be used
  2. Last Completed: If no schedule, the last completed investment amount is used
  3. Default: ₹50,000 if no previous investments exist
When Schedule is Used:
  • When preparing next month's cycle
  • When running "Prepare Next Month" workflow cleanup
  • Only if schedule is active and within start/end date range
