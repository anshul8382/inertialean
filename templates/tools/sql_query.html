Security Notice

Only SELECT queries are allowed. Data modification operations (INSERT, UPDATE, DELETE, DROP, etc.) are blocked for security reasons.

Important Notes
  • Net Investment: Calculated from cashflow table (negative amounts = investments, positive = withdrawals)
  • Current Value: Calculated from holding table (quantity × security.current_price)
  • % Return: Calculated as ((Current Value - Net Investment) / Net Investment) × 100
  • XIRR: Cannot be calculated in SQL - requires iterative calculation. Use the API endpoint /api/v1/<client_id>/performance/xirr or check portfolio_snapshot table for stored XIRR values.
