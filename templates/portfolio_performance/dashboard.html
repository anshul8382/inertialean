How Portfolio Performance Monitor works

  • Full portfolio: For equity-only clients, compares portfolio XIRR with Nifty benchmark XIRR.
  • Equity-only: For clients with other assets (e.g. debt, gold), compares only equity holdings XIRR with the same benchmark.
  • Issues: Creates an issue when portfolio/equity XIRR is below benchmark (critical if underperformance > 5%, else warning).
  • Resolution and workflow match the Data Integrity pattern (resolve, bulk resolve).
